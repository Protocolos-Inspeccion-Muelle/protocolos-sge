4. REGISTRO DE CALIBRACIÓN Y PRUEBA DE LAZOS

Instrumento / TAGRangoValor patrónLectura localLectura HMI / DCSmA medidoError (%)mA esperado / errorLazo OK
Rangos permisibles: Error % = (lectura HMI/DCS − valor patrón) / span × 100: ≤ ±1 % OK ≤ ±2 % revisar > ±2 % fuera de tolerancia. mA esperado = 4 + 16 × (patrón − mín) / span; error en mA: ≤ ±0,16 mA ≤ ±0,32 mA mayor; señal < 3,8 mA o > 20,5 mA = falla NE43. Ingresar el rango como "mín – máx" (ej. 0 – 250 bar) para que se calcule solo. Completar los TAG y rangos según el índice de instrumentos del proyecto.
